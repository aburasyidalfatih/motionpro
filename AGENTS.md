# MotionPro

AI-assisted studio for military history and geopolitics motion-graphic videos (Indonesian UI). Plan and phases: see README and the PRD linked there.

- Stack: Next.js 16 (App Router) + Tailwind 4, Prisma 7 (`prisma-client` generator, `@prisma/adapter-pg`, client in `src/generated/prisma`), BullMQ + ioredis, Remotion 4 (all `remotion`/`@remotion/*` packages pinned to the same exact version).
- Web only enqueues jobs (`enqueueJob` in `src/lib/queue.ts`); the worker (`src/worker`) does the work and writes status/progress to `JobRun`. Add a pipeline stage by adding a handler to the `handlers` map in `src/worker/index.ts`.
- Pages that read the database call `await connection()` so they are not prerendered at build time.
- AI calls go through the `ScriptAI` interface (`src/lib/ai`): Gemini in production, `AI_PROVIDER=fake` for tests without an API key. Output shapes are zod schemas in `src/lib/ai/schemas.ts`, sent to Gemini as JSON Schema and used to validate the response.
- Files live in `STORAGE_DIR` and are referenced by relative path (`src/lib/storage.ts`), served by `/api/files/...`; music/SFX come from `library/` via `/api/library/...`. Asset and audio stage status is derived from data by `recomputeStatus` (`src/lib/project-status.ts`); call it after changing scenes, assets or voiceovers.
- Jobs whose input has a `sceneId` are scene-level (`isSceneJob`): they never mark the project FAILED and don't lock the page.
- Polling for job progress (`AutoRefresh`) lives in pages, not in `projects/[id]/layout.tsx`: layouts are not re-rendered when switching tabs inside a project.
- Scenes have a `visualType`; graphic types (`title`, `kinetic_text`, `map`, `timeline`, `stat`, `chart`, `comparison`, `profile`, `quote`) are drawn by the template from `Scene.graphicData` (shape: `graphicDataSchema`), only `painting`/`archival_photo`/`footage`/`illustration` need assets (`needsAsset`). `illustration` images are generated by Gemini in the ASSETS job (`src/lib/ai/image.ts`, asset provider `gemini`); project `style` GRAPHIC forbids only third-party types (`isThirdPartyVisual`, `normalizeScene`).
- Research runs in two rounds (`runResearch`, `src/lib/ai/research-pipeline.ts`); the script is written in stages (`writeFullScript`, `src/lib/ai/script-pipeline.ts`): outline with chapters and open loops → each part written → each part reviewed. The first `title` scene is the video title card, later `title` scenes open chapters (`chapterNumbers`); per-chapter music and chapter cards depend on this.
- Graphic elements appear when the narrator says them: items carry an optional `cue` (words from the narration) matched against voice-over word timings by `beatFrames` (`src/remotion/history/beats.ts`), read by components through `SceneSpeechContext`. Beat-synced SFX use the same cue builders.
- Word timings (`Voiceover.wordTimestamps`) come from the voice-over audio: `pausedWordTimings` (pauses matched to punctuation), refined by Whisper (`src/lib/tts/whisper.ts`, `@remotion/install-whisper-cpp`) when `WHISPER_MODEL` is set; the AUDIO job with `realign` recomputes them without new TTS.
- Finishing (`src/remotion/history/finishing.tsx`): grain, grade, vignette, light leaks (`@remotion/effects`, WebGL2) and transition motion blur (`HtmlInCanvasMotionBlur`, only when `isHtmlInCanvasSupported()`, otherwise it would cancel the Player preview). Renders are mastered to -14 LUFS afterwards (`src/lib/video/master.ts`, Remotion's bundled ffmpeg).
- Video template: `src/remotion/history/` (plain props, relative imports only, no `@/` alias: it is bundled by Remotion's webpack). Props are built from the DB by `buildVideoProps` (`src/lib/video/props.ts`) with a `UrlResolver`: browser URLs for the Player, a worker-local static server for rendering. Template fonts are local files in `public/fonts` loaded by `src/remotion/history/fonts.ts` (`@remotion/fonts` + `staticFile`), so rendering needs no internet. Map layers (land, borders from `world-atlas`; rivers, lakes, cities in `src/remotion/history/data`, regenerated by `npm run map:data`) come from Natural Earth; static layers are rasterized once per scene by `MapBase` because redrawing thousands of SVG paths every frame is slow.
- Checks before committing: `npm run typecheck`, `npm run lint`, `npm run build`.
- UI copy is in Indonesian.
